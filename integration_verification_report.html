Severity: Low — Does not block integration. NGO is created correctly in database; the ID can be retrieved via GET /api/v1/auth/me or by querying the database.

Required Owner: Person 1

Fix Made: None — documented as known issue. Integration tests work around this by using existing NGO IDs from database.
